# 乡村摄影巡展授权与作品回收

管理乡村摄影展作品授权、场地借展、巡展运输和撤展赔付。

## 参与方与事实

主要参与方包括摄影大展运营方、摄影师与机构、村落场地负责人、巡展承运人、保险与版权审核人员。领域资料记录以下已经确认的事实：

- 贵州原生态国际摄影大展在荔波县洪江村开幕
- 线上线下展出1000余幅作品并融入村落实景
- 活动将持续至12月31日并计划开启中亚巡展

## 业务约束

- 作品授权版本
- 村落场地容量
- 布展交接
- 巡展运输与保险
- 撤展与赔付追溯

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_002.py` 负责读取和校验这些资料。

## 作品与场地服务

`src/exhibition_service.py` 在领域资料之上实现可运行的服务，`docs/domain-rules.md` 描述其规则：

- 作品登记、原始文件 SHA-256 指纹去重；重复上传返回原结果，指纹相同但授权不同则生成新版本并进入他人复核
- 授权按地域与期限生效，到期/撤销后不能进入新场次；排展时固化授权与译文快照，闭展场次保留当时版本
- 展点容量控制、村民仅见本人场地、授权人不能自批例外、联系方式不被检索枚举且查阅留审计
- 场地关闭、作品受损或跨境运输延误只冻结受影响批次，其余展点照常推进，恢复后接续作业
- 布展交接、闭展回收、损坏赔付核对，以及对任一作品“为何获准、由谁交接、何时回收”的追溯解释
- 到期提醒、撤展清点、赔付核对以水位标记持久化，服务重启后不重复、不遗漏
