# 乡村摄影巡展授权与作品回收

管理乡村摄影展作品授权、场地借展、巡展运输和撤展赔付。

## 参与方与事实

主要参与方包括摄影大展运营方、摄影师与机构、村落场地负责人、巡展承运人、保险与版权审核人员。领域资料记录以下已经确认的事实：

- 贵州原生态国际摄影大展在荔波县洪江村开幕
- 线上线下展出1000余幅作品并融入村落实景
- 活动将持续至12月31日并计划开启中亚巡展

## 业务约束

- 作品授权版本
- 村落场地容量
- 布展交接
- 巡展运输与保险
- 撤展与赔付追溯

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_002.py` 负责读取和校验这些资料。

## 作品与场地服务

`src/service.py` 在领域资料之上提供可持久化的作品与场地服务 `ExhibitionService`，
`src/store.py` 负责状态的原子写入，规则细则见 `docs/domain-rules.md`：

- 作品以原始文件指纹建档；重复上传幂等返回原结果，同指纹不同授权进入复核
- 授权版本不可改、只能更替；到期或地域不覆盖的授权不能准入新场次
- 授权例外须他人审批——提交人不能批准自己的例外
- 展点容量、村民本场地视角、敏感联系方式受保护且查看留痕
- 场地关闭、作品受损、跨境延误只冻结受影响批次，其他展点照常推进
- 布展/撤回交接链、撤展清点、完成场次版本快照、保险赔付核对
- 服务重启后凭状态文件接续到期提醒、撤展清点与赔付核对
- `explain(作品, 场次)` 解释作品为何获准、由谁交接、何时回收
