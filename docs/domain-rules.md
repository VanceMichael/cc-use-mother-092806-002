# 领域边界

管理乡村摄影展作品授权、场地借展、巡展运输和撤展赔付。

现有领域资料围绕以下边界组织：

- 作品授权版本
- 村落场地容量
- 布展交接
- 巡展运输与保险
- 撤展与赔付追溯

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

# 服务规则（src/service.py）

## 参与方与角色

- `operator` 摄影大展运营方：排场次、编排批次、登记译文、关闭/重开场地、结案赔付。
- `author` 摄影师与机构：提交作品与授权。
- `venue_manager` 村落场地负责人：只能查看与操作本场地，参与布展/撤回交接。
- `carrier` 巡展承运人：编排批次、布展交接、上报跨境延误与作品受损。
- `reviewer` 保险与版权审核人员：复核授权版本、审批授权例外、核对赔付。

## 作品与授权版本

1. 作品以原始文件 64 位指纹（SHA-256）建档；指纹不同即为不同作品。
2. 同一作品重复上传且授权关键条款（地域、起止日、范围）完全相同：幂等返回原作品与原授权，不产生新版本。
3. 指纹相同但授权条款不同，或提交作者与登记作者冲突：生成新版本并进入 `pending_review`；复核期间不可使用，场次仍以当前生效授权为准。
4. 复核由 `reviewer` 完成：通过后新版本成为当前生效版本，旧版本标记 `superseded`；驳回则新版本为 `rejected`，旧版本继续有效。
5. 授权状态：`active` / `pending_review` / `rejected` / `superseded`，授权不可就地修改，只能以新版本更替。

## 场次准入闸门

准入裁决 `admit(artwork, show)` 必须同时满足，并把每条理由落盘：

- 场次未完成；作品有 `active` 授权版本（待复核、被驳回、被取代均不可用）。
- 授权到期日不早于场次结束日；授权地域包含场次地域。期限或地域不足可凭已批准的对应类型例外（`expiry` / `territory`）放行。
- 展点未关闭；已准入数量未达到展点容量；作品相关批次未冻结。
- 授权即将/已经到期时不得再准入新场次；到期提醒在窗口内逐日扫描，已逾期授权继续提醒直到续签，同一天不重复提醒。

## 授权例外

- 例外分 `territory` 与 `expiry` 两类，先有申请再有结论，结论只能是批准或驳回。
- 提交授权的人不能批准自己的例外（按提交人账号判定，即使其具备审核角色也禁止）。

## 场地、批次与冻结隔离

- 展点有容量与 `open`/`closed` 状态；村民视角 `venue_schedule` 只返回本场地的场次与准入作品，负责人账号互不可见。
- 冻结只作用于单个批次：场地关闭只冻结该场地未完成场次的在途批次；作品受损只冻结所属批次；跨境运输延误只允许对跨境批次上报。其他展点与批次照常推进。
- 冻结原因：`venue_closed` / `artwork_damaged` / `cross_border_delay`；解冻登记冻结历史，流程接续，不回滚此前裁决。
- 冻结批次不得布展；解冻后布展、到期提醒、撤展清点、赔付核对照常继续。

## 布展交接与撤展

- 布展必须先有准入通过记录；交接链按时间记录 `installed` / `returned` / `damaged`，含交接双方、操作人与时间。
- 在同一展览中，已布展未撤回的作品不能重复布展；未布展的不能撤回；撤回记录回答"由谁交接、何时回收"。
- 撤展清点对全部准入作品给出 `returned` / `outstanding` / `damaged`，存在未回收作品时清点不完整。

## 完成快照与翻译

- 场次完成时固化快照：每件作品当时的授权版本（地域、期限、范围）、适用例外、布展/撤展交接、译文版本指纹。
- 完成后的场次拒绝新准入、新批次和新布展；事后更新的授权与译文不影响已完成展览，解释仍指向快照版本。
- 展签译文按作品与语言版本化；相同文本重复提交返回原版本。

## 保险与赔付

- 批次可登记保险单；赔付申请必须引用真实的损坏交接记录，同一损坏事件重复申报幂等。
- 赔付核对要求损坏记录、批次保单一致且赔付金额不超过保额；核对通过后方可结案赔付。

## 隐私与可解释性

- 作者联系方式存放在受保护区，任何检索（作者检索、作品目录、场地安排）都不返回联系方式；联系方式仅运营方与审核人员可查看，每次查看写审计记录。
- `explain(artwork, show)` 汇总准入裁决与全部理由、授权版本、交接链与回收时间；已完成场次额外返回固化快照。

## 持久化

所有状态经原子写入的 JSON 存储落盘；服务用同一状态文件重建后，冻结状态、到期提醒、撤展清点与赔付核对均能接续。
