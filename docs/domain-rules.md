# 领域边界

管理乡村摄影展作品授权、场地借展、巡展运输和撤展赔付。

现有领域资料围绕以下边界组织：

- 作品授权版本
- 村落场地容量
- 布展交接
- 巡展运输与保险
- 撤展与赔付追溯

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 服务规则（`src/exhibition_service.py`）

### 作品、指纹与授权

- 作品以原始文件 SHA-256 指纹去重：指纹与授权地域、期限完全一致的重复上传直接返回原作品与原授权。
- 指纹相同但授权地域或期限不同时，沿用原作品并生成递增版本的新授权，状态为待复核，复核通过前不得排入新场次。
- 授权按地域与展期生效；到期、被撤销或地域不覆盖的作品不能进入新场次。
- 授权到期前 30 天生成一次到期提醒。
- 提交授权或授权例外的人不能复核/批准自己的申请。

### 场次快照

- 作品排入场次时，固化所依据的授权或例外（编号、版本、地域、期限、提交人与批准人）以及当时各语种译文版本。
- 场次闭展后快照与展品清单不可变；此后授权到期、撤销或译文修订都不影响历史场次的解释。

### 场地、容量与角色

- 每个展点有容量上限，超出容量拒绝排展；关闭的场地不能安排新场次或新增展品。
- 村民（VENUE_HOST）通过场地看板只能看到本人负责场地的场次与安排。
- 作者联系方式不进入任何检索/列表结果；仅运营与保险角色可凭明确理由查阅，查阅写入审计。

### 批次冻结与恢复

- 巡展按批次推进。场地关闭、作品受损、跨境运输延误只冻结受影响批次，其他批次的展点照常开展。
- 冻结期间该批次的交接、开展等推进操作被拒绝；批次恢复后可继续。

### 交接、回收与赔付

- 开展前每件作品必须完成布展交接（交付人、接收人、时间、品相）；闭展后才能记录撤展回收，交接不可重复登记。
- 作品受损登记后自动产生赔付单并冻结所在批次，由保险角色核对确认金额或拒赔。
- `explain_placement` 可解释任一作品在任一场次为何获准、谁与谁在何时交接、何时回收及赔付结论。

### 续跑与持久化

- 到期提醒、撤展清点清单、赔付核对通知通过水位标记去重；状态可整体落盘为 JSON。
- 服务重启后从水位标记续跑：已发出的不重复，新增事项不遗漏；冻结状态与赔付进度一并恢复。
